## 2026年度 B3 向け 100本ノックのテストリポジトリ
進め方にはいくつかバージョンがありますが、基本的に最新のものを採用してください。

### 進め方 v0.2
- 各自でGitHubリポジトリを作成し、main ブランチ上で進捗を管理する
- 毎週、指定された範囲まで取り組む
- 先輩が各リポジトリを確認し、Issue上でレビューする
    - 問題がなくてもIssueを投げます
- 指摘がある場合は修正し、確認後にIssueをCloseする

### 進め方 v0.1
- 各自でGitHubリポジトリを作成し、進捗を管理する
- 基本的に `main` ブランチ上で作業する
- 週ごとに、その週に取り組んだ範囲をIssueで提出する
- 先輩が対象のコミットをレビューし、必要に応じてコメントする
- 指摘があれば修正し、問題なければIssueをCloseする

本リポジトリは上記の手順をシミュレーションテストするためのものです。
